## Bash

### Домашнее задание:

Написать написать bash-скрипт (для CRON), который ежечасно формирует и отправляет на заданный email отчёт о работе веб-сервера;  

Отчёт должен содержать:

* IP-адреса с наибольшим числом запросов (с момента последнего запуска);
* Запрашиваемые URL с наибольшим числом запросов (с момента последнего запуска);
* Ошибки веб-сервера/приложения (с момента последнего запуска);
* HTTP-коды ответов с указанием их количества (с момента последнего запуска).

Скрипт должен предотвращать одновременный запуск нескольких копий, до его завершения

В письме должен быть прописан обрабатываемый временной диапазон

### Формирование скрипта.

В связи с отсутсвием собственного веб-сервера, в целях тестирования работы скрипта, будем использовать лог файл прикреплённный к занятию (access.log)

Расположим его по пути `/home/user/logs/access.log`

Создадим файл скрипта по пути `/home/user/scripts/web_report.sh`

Убедимся, что у скрипта есть права на выполнение для владельца: 

```bash
chmod 755 web_report.sh
```

**Для предотвращения повторного запуска уже исполняемого скрипта** - используем утилиту flock

Использовать можно через CRON, если скрипт автоматически запускается через него:

```bash
crontab -e
```

```bash
0 * * * * /usr/bin/flock -n /var/lock/script.lock /home/user/scripts/web_report.sh
```

Либо добавив в скрипт перед исполняемой частью: 

```bash
#!/bin/bash
exec 200>/var/lock/script.lock
flock -n 200 || { echo "Скрипт уже выполняется!"; exit 1; }
```

Мы будем использовать вариант через CRON

**Добавим проверку на доступность лога:**

```bash
if [ ! -f "$LOG_FILE" ]; then
    echo "Лог-файл не найден!" | mail -s "Возникла проблема!" "$EMAIL"
    exit 1
fi
```

Здесь `[ ! -f "$LOG_FILE" ]` проверяет, существует ли вообще файл лога

Если веб-сервер упал, удалил лог или у скрипта нет прав на чтение, скрипт не упадет молча: он отправит нам письмо об ошибке и завершит работу `exit 1`, не выполняя код дальше

Оформим в функцию `check_file()`

**Создание промежуточного лог-файла:**

Лог-файл представляет из себя файл содержащий строки вида: 

```log
188.43.241.106 - - [14/Aug/2019:09:17:16 +0300] "GET /favicon.ico HTTP/1.1" 200 7358 "-" "Mozilla/5.0 (Windows NT 10.0; WOW64; rv:68.0) Gecko/20100101 Firefox/68.0"rt=0.000 uct="-" uht="-" urt="-"
```

Нам нужно вырезать из огромного файла только строки за прошлый час и сохранить их в временный файл

Для начала зададим временные переменные:

Здесь мы временно переключаем язык системы на стандартный английский, а затем берем текущее время, отнимает от него ровно час и форматируем под формат нашего лога

```bash
TARGET_DATE=$(LC_ALL=C date -d "1 hour ago" +"%d/%b/%Y:%H")
```
Здесь мы формируем текстовые переменные, которые будут вставлены в шапку письма

```bash
TIME_START=$(LC_ALL=C date -d "1 hour ago" +"%Y-%m-%d %H:00:00")
TIME_END=$(LC_ALL=C date -d "1 hour ago" +"%Y-%m-%d %H:59:59")
```

Оформим в функцию `set_time()`

Создаем пустые временные файлы в системной директории `/tmp` с уникальными именами

А с помощью `trap '...' EXIT` удалим их по окончании работы скрипта

```bash
TMP_LOG=$(mktemp)
REPORT_FILE=$(mktemp)
trap 'rm -f "$TMP_LOG" "$REPORT_FILE"' EXIT
```

Ищем в файле логов точное совпадение строки: подстроки вида `[16/Sep/2026:16:`с текущей датой и прошедшим часом, копируются во временный файл

```bash
grep -F "[$TARGET_DATE:" "$LOG_FILE" > "$TMP_LOG"
```

Если за прошлый час на сайт никто не заходил (файл пуст), скрипт отправляет короткое уведомление "Запросов не обнаружено" и завершает работу

```bash
if [ ! -s "$TMP_LOG" ]; then
    (
    echo "Отчет о работе веб-сервера"
    echo "Период: $TIME_START — $TIME_END"
    echo "* * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * *"
    echo "За указанный период запросов не обнаружено."
    ) | mail -s "Веб-сервер: Отчет за $TIME_START" "$EMAIL"
    exit 0
fi
```

**Фильтрация промежуточного лог-файла:**

1. IP-адреса с наибольшим числом запросов:

Так как в нашем логе первая колонка всегда IP-адрес - используем `awk '{print $1}'`

Сортируем по алфавиту - `sort`

Обьединим одинаковые IP-адреса и подсчитаем количество повторений `uniq -c`

Сортируем получившийся список в числовом порядке по убыванию `sort -rn`

Отбрасываем всё кроме первых десяти строк `head -n 10`

```bash
awk '{print $1}' "$TMP_LOG" | sort | uniq -c | sort -rn | head -n 10
```

2. Запрашиваемые URL с наибольшим числом запросов:

Так как в нашем логе запрос выглядит как `"GET /admin/config.php HTTP/1.1"` - 

Разделяем строку по символу `"` и берём второй блок, затем разделяем строку по пробелам и забираем второе слово - сам URL

`awk -F'"' '{print $2}' "$TMP_LOG" | awk '{print $2}'`

А далее сортировка, как и в предыдущем случае `sort | uniq -c | sort -rn | head -n 10`

```bash
awk -F'"' '{print $2}' "$TMP_LOG" | awk '{print $2}' | sort | uniq -c | sort -rn | head -n 10
```

3. Ошибки веб-сервера/приложения:

Так как сразу после блока с URL в каычках идет блок кодов ответов `404 29500 "-"` - 

Берём третью часть (все, что после вторых кавычек) `awk -F'"' '{print $3}'`

Берём первое слово из этого блока которое и есть HTTP код `awk '{print $1}'`

Далее сортировка от частых к редким `sort | uniq -c | sort -rn`

```bash
awk -F'"' '{print $3}' "$TMP_LOG" | awk '{print $1}' | sort | uniq -c | sort -rn
```

4. HTTP-коды ответов с указанием их количества:

Здесь мы берем блок, как в предыдущем шаге и проверяем его регулярным выражением `/^[45]/` - начинается ли код на цифру 4 или 5, то есть ошибки клиента или сервера

Если условие выполняется, он формирует строку, соединяя в ряд сам код, IP-адрес и URL, на котором эта ошибка произошла.

```bash
    awk -F'"' '{ 
        split($3, status, " "); 
        if (status[1] ~ /^[45]/) { 
            print "Код: " status[1] " | IP: " $1 " | URL: " $2 
        } 
    }' "$TMP_LOG" | sort | uniq -c | sort -rn | head -n 20
```

Оформим в функцию `generate_report()`

Все эти выводы с помощью оператора `> "$REPORT_FILE"` запишем в один общий текстовый файл отчета

**Отправка отчёта:**

Команда `mail` берет содержимое файла `$REPORT_FILE` (через знак `<`), подставляет тему письма с датой начала диапазона и отправляет на наш email через настроенный ранее `msmtp`

```bash
mail -s "Веб-сервер: Отчет за $TIME_START" "$EMAIL" < "$REPORT_FILE"
```
