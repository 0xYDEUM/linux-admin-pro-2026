## Управление процессами

### Домашнее задание:

#### Вариант 1. Реализация аналога ps ax

* Создайте скрипт, который получает информацию о процессах через файловую систему /proc
* Реализуйте вывод не менее следующих полей: PID, PPID, состояние процесса, имя или команда запуска
* Проверьте работу скрипта на запущенной системе
* Зафиксируйте пример результата работы

**Ожидаемый результат:** рабочий скрипт, выводящий список процессов по данным из /proc

### Выполнение:

Создадим файл скрипта по пути `/home/user/scripts/` и сделаем его исполняемым

```bash
nano /home/user/scripts/ps_ax.sh
```

```bash
chmod +x /home/user/scripts/ps_ax.sh
```

Поскольку вывод работы нашего скрипта лучше представить в виде таблицы - вместо `echo` используем `printf`. Зададим выравнивание по левому краю и зарезервируем ширину столбцов по 10 символов для всех кроме последнего

Формируем заголовок таблицы

```bash
printf "%-10s %-10s %-10s %s\n" "PID" "PPID" "STATUS" "COMMAND"
```

Так как каждому запущенному процессу соответствует поддиректория в директории `/proc`, названная его идентификатором (PID) - составим регулярное выражение находяшее только директории с цифровым названием

```bash
for pid_dir in /proc/[0-9]*/; do
```

С помощью утилиты `basename` которая извлекает из заданного пути только имя файла (или имя каталога), удаляя при этом путь к каталогу - запишем в переменную `pid` номер процесса

```bash
pid=$(basename "$pid_dir")
```

Файл `/proc/[PID]/stat` содержит основную информацию о процессе в одну строку, где данные разделены пробелами

Для извлечения необходимых данных, читаем stat целиком как строку

Находим самую последнюю закрывающую круглую скобку `)` (именно там заканчивается имя процесса). Всё, что идет до неё, мы отбрасываем с помощью конструкции `${stat_line##*)}`
Разбиваем оставшуюся часть строки в массив

Добавляем в переменные `status` и `ppid` соответсвующие элементы массива

Добавим проверку на случай если процесс завершится в момент работы цикла

```bash
if [ -f "${pid_dir}stat" ]; then

        stat_line=$(cat "${pid_dir}stat")

        stat_after_name="${stat_line##*)}"
        stat_fields=( $stat_after_name )

        status="${stat_fields[0]}"
        ppid="${stat_fields[1]}"
```

Файл cmdline содержит полную команду, которой был запущен процесс. Однако аргументы внутри него разделены не пробелами, а нулевыми байтами `\0`

![IMG2]()

Чтобы корректно прочитаь этот файл воспользуемся командой `xargs -0` она заменяет нулевые байты на пробелы и корректно читает файлы без символа новой строки в конце

Инициализируем переменную пустой строкой

```bash
 command=""
    if [ -f "${pid_dir}cmdline" ]; then
    command=$(xargs -0 < "${pid_dir}cmdline" 2>/dev/null)
    fi
```

Добавим проверку на случай если cmdline оказался пуст (длина строки равна 0) или команда `xargs` не вернула ничего - берем системное имя из файла `comm` и по аналогии с настоящей утилитой `ps` оборачивает его в квадратные скобки

```bash
if [ -z "$command" ]; then
    command="[$(cat "${pid_dir}comm" 2>/dev/null)]"
fi
```

И наконец формируем строки таблицы по аналогии с заголовком

```bash
printf "%-10s %-10s %-10s %s\n" "$pid" "$ppid" "$status" "$command"
```

Добавим алиас для нашего скрипта, пусть вызывается командой `ax`

Чтобы алиас работал в каждой сессии, добавим строку с alias в ~/.bashrc

```bash
echo "alias ax='/home/user/scripts/ps_ax.sh'" >> ~/.bashrc
```

```bash
source ~/.bashrc
```

Проверим, что алиас подхватился

```bash
type ax
```
