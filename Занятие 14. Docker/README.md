**Можно ли в контейнере собрать ядро?**

По своей архитектуре Docker-контейнеры делят ядро с хостовой системой. Это значит, что внутри контейнера доступно только то ядро, которое работает на хосте. Поэтому ответ скорее отрицательный. Однако существует образ https://hub.docker.com/r/tomzo/buildkernel, который якобы позволяет собирать ядро из локальных исходных кодов прямо в контейнере. Правда обновлялся он последний раз в Декабре 2015 года.
